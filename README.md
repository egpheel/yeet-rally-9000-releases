# Yeet Rally 9000: alpha builds

A rally game on real roads: 42 stages in 14 countries, built from OpenStreetMap and real elevation data.

This repo only holds the builds. Grab the latest from **[Releases](../../releases/latest)**:

- **Windows** (64-bit): unzip, then run `YeetRally9000.exe`. If SmartScreen stops it: More info, then Run anyway.
- **macOS** (Apple silicon and Intel): unzip, then right-click `Yeet Rally 9000.app` and choose Open the first time.
  If macOS says the app is damaged, run `xattr -cr "Yeet Rally 9000.app"` in Terminal, then open it again.

It's a very early alpha and free to play. It'll be a paid game when it comes out on Steam.
